# ExpenseIQ

ExpenseIQ is an AI-powered expense intelligence platform that helps users understand their spending patterns using data visualization and AI-generated insights.

## Features (Planned)
- Upload bank statements (CSV/XLSX)
- Automatic expense categorization
- Interactive charts and tables
- AI-generated spending insights
- Single-page dashboard with robust error handling

## Tech Stack
**Frontend**
- React
- TypeScript
- Vite

**Backend**
- Node.js
- Express (planned)

**AI**
- Gemini API

> Project is currently under development.
